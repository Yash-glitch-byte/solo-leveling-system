# ⚔️ Solo Leveling: "The System"

> **[SYSTEM NOTIFICATION: A new Player has awakened.]**  
> Turn your daily life into Sung Jin-woo's leveling system. Complete daily training quests, enter instant dungeons for deep focus work, gain EXP, and upgrade your attributes.

---

## ✨ Features

- **Iconic System HUD**: Futuristic dark obsidian glassmorphism UI with electric cyan glow and responsive grid.
- **Player Status Window**:
  - Live **EXP Bar** with level-up thresholds.
  - **HP (Physical Energy)** and **MP (Mental Focus)** vitals.
  - Core Attributes: **STR** (Strength), **INT** (Intelligence), **AGI** (Agility), **VIT** (Vitality), and **PER** (Perception).
  - Stat point allocation (+5 free points on each level-up).
- **Daily Quests ("Preparing to Become Strong")**:
  - Pre-loaded habits for workout, study, hydration, and focus.
  - Custom task creation with attribute affinities.
  - Daily completion tracker and **Blessed Random Box** daily loot reward.
- **Instant Dungeon (Focus Chamber)**:
  - Built-in 25-minute Pomodoro timer for zero-distraction deep work.
  - Clearing the dungeon grants bonus EXP and Perception stat points.
- **Web Audio Sound Effects**:
  - Synthesized system chimes, alert pings, stat boosts, and Level Up fanfares (runs 100% offline with zero dependencies).
- **Persistent Data**:
  - Automatically saves all hunter data, levels, and stats to your browser's local memory (`localStorage`).

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<YOUR-USERNAME>/solo-leveling-system.git
   ```
2. Navigate to the project directory:
   ```bash
   cd solo-leveling-system
   ```
3. Open `index.html` in your browser (Google Chrome, Microsoft Edge, Firefox, Brave):
   - Simply double click `index.html` or run:
   ```bash
   python -m http.server 3000
   ```
   - Open `http://localhost:3000` in your browser.
