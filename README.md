# ⚔️ Solo Leveling: "The System" (v2.0)

> **[SYSTEM NOTIFICATION: A new Player has awakened.]**  
> Turn your daily life into Sung Jin-woo's leveling system. Complete daily training quests, enter instant dungeons for deep focus work, gain EXP, upgrade attributes, extract shadow commanders, equip legendary hunter weapons, and survive the dreaded Penalty Zone.

---

## ✨ Features

- **Iconic System HUD**: Futuristic dark obsidian glassmorphism UI with electric cyan and abyss purple glow, responsive scanlines, and animated sci-fi badges.
- **Player Status Window**:
  - Live **EXP Bar** with dynamic level-up scaling and hunter rank progression (E-Rank up to National Level and Shadow Monarch).
  - **HP (Physical Energy)**, **MP (Mental Focus)**, and **FATIGUE Gauge** (0-100%).
  - Core Attributes: **STR** (Strength), **AGI** (Agility), **VIT** (Vitality), **INT** (Intelligence), and **PER** (Perception).
  - Effective stat calculation combining base stats, equipped weapons/armor, and active shadow buffs.
  - Stat point allocation pool (+5 points per level-up, +2 points per Blessed Random Box).
- **Daily Quests ("Preparing to Become Strong")**:
  - Pre-loaded habits for physical workout, intellect study, hydration, and mental focus.
  - Custom daily quest creation with attribute affinity tags and custom EXP.
  - Daily completion tracker and **Blessed Random Box** loot rewards (potions, items, stat boosts).
- **Dungeon Gates & Boss Raids**:
  - Multi-tier Gates: **E-Rank Subway**, **D-Rank Kasaka's Lair**, **C-Rank Red Gate**, **B-Rank High Orc Crypt**, **A-Rank Demon Castle**, and **S-Rank Jeju Island**.
  - Interactive Pomodoro focus timer with dynamic **Boss Health Bar** that takes damage as you maintain deep focus!
  - Defeating gate bosses unlocks rare weapons (Kasaka's Fang, Baruka's Dagger) and opens souls for shadow extraction.
- **Shadow Army & Extraction ("ARISE")**:
  - Extract iconic shadows: **Igris (Blood-Red Commander)**, **Tank (Ice Bear Alpha)**, **Iron (Heavy Armored Knight)**, **Tusk (High Orc Shaman)**, **Kaisel (Shadow Wyvern)**, and **Beru (Ant King)**.
  - Interactive "ARISE" summoning ceremony with synthesized dark harmonic resonance sound effects.
  - Deploy up to 3 active shadow commanders to bestow permanent passive combat multipliers.
- **Hunter Equipment & Inventory**:
  - Dedicated equipment slots: `[WEAPON]`, `[ARMOR]`, and `[ACCESSORY]`.
  - Storage backpack with item rarity tiers (Common, Rare, Epic, Legendary).
  - Consumable items like the **Full Recovery Potion** that restores 100% HP & MP and purges fatigue.
- **The Penalty Zone (Emergency Survival)**:
  - If daily quests are missed, the system activates the Penalty Zone protocol.
  - 10-minute emergency survival sprint / workout trial with alert siren audio.
  - Surviving clears 100% fatigue, awards +100 EXP, and bestows the "Surviving Hunter" title.
- **Web Audio Sound Effects Synthesizer**:
  - 100% client-side synthesized audio (system alerts, chimes, level-up fanfare, "ARISE" chord resonance, boss attack slashes, and sirens). Runs offline with zero external audio files.
- **Data Persistence & Portable Backups**:
  - Automatically saves all progress to browser `localStorage`.
  - Built-in **Backup (Export JSON)** and **Restore (Import JSON)** to easily transfer saves across devices.
- **Progressive Web App (PWA)**:
  - Installable directly to your Android or iPhone home screen with offline caching.

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Yash-glitch-byte/solo-leveling-system.git
   ```
2. Navigate to the project directory:
   ```bash
   cd solo-leveling-system
   ```
3. Open `index.html` in any modern web browser, or launch a local dev server:
   ```bash
   python -m http.server 3000
   ```
   Open `http://localhost:3000` in your browser.
